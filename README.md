# NEXORA - Tecnología e Innovación

## Descripción
Página web desarrollada para el examen parcial de Diseño Web de la UCH.

Presenta servicios tecnológicos, una galería de imágenes y contenido multimedia.

## Tecnologías utilizadas
- HTML5
- CSS3
- Etiquetas semánticas
- Diseño responsive
- Float y clear
- Transiciones y animaciones
- Media Queries
- SEO básico
